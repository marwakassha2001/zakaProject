# 🖊️📘 Pen & Book Object Detection (YOLOv8)

Live Demo: https://YOUR-RENDER-URL

## Description
A YOLOv8-based object detection web application that detects pens and books in images.
Built with:
- YOLOv8 (Ultralytics)
- Flask
- Docker
- Render

## How it works
1. Upload an image
2. The model detects Pen / Book
3. Results are displayed with bounding boxes

## Deployment
The app is containerized with Docker and deployed on Render.
